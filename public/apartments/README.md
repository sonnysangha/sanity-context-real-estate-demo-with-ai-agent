# Fictional apartment imagery

Each of the thirteen listings has a distinct AI-generated interior image. These images illustrate fictional properties and do not depict verified rentals. They are provided with the tutorial under the repository license; images are not evidence of real property details.

The listing-to-file mapping is in [seed/listings.json](../../seed/listings.json). All images are included locally for upload to your own Sanity project; no image-generation account is needed.

Run `pnpm seed` for a new project. Use `pnpm seed:images` to replace only the image field on existing tutorial listings while preserving other content edits.
